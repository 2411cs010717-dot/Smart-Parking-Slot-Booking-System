# AI-Based Parking Management System

A student-friendly web application built using HTML, CSS, JavaScript, Python Flask, MySQL, and CNN with TensorFlow/Keras.

## Features
- User and Admin Login
- Parking Slot Booking
- Booking History
- Admin Slot Management
- CNN-Based Parking Occupancy Classification
- Two-Wheeler and Four-Wheeler Slot Selection
- Booking Cancellation
- Date and Time Conflict Checking

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: MySQL
- Deep Learning: CNN, TensorFlow, Keras

## How to Run
1. Install Python and MySQL.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Configure the MySQL database using `database/parking.sql`.
4. Configure the `.env` file.
5. Train the CNN model.
6. Run the application using `python app.py`.
7. Open `http://127.0.0.1:5000` in your browser.
